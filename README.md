# 吕郎杰个人求职网站

面向海外销售、外贸业务与国际客户开发岗位的多页面个人品牌网站。当前公开版不包含手机号、证件照、精确位置或原始 PDF；经本人授权，公开使用部分旅行照片作为个人品牌视觉素材。

## 本地预览

可直接双击 `index.html` 打开。为了获得最稳定的字体与下载体验，也可以在项目目录运行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。
