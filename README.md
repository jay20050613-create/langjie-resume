# 吕郎杰个人求职网站

面向海外销售、外贸业务与国际客户开发岗位的多页面候选人档案网站。内容以真实经历、可核实的过程量化、工作方式与跨文化视野为主，不展示未经验证的业绩数字。当前公开版不包含手机号、证件照、个人旅行照片、精确位置或原始 PDF；视觉由纯 HTML、CSS、JavaScript 与内联 SVG 构成，不依赖本地文件路径。

## 本地预览

可直接双击 `index.html` 打开。为了获得最稳定的字体与下载体验，也可以在项目目录运行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。
